# GimbalX Report - 发布包分发

本仓库**只存放安装包**，源码在私有仓库 `terrychen111/gimbalx-report`。

- 下载：[Releases](https://github.com/terrychen111/gimbalx-report-dist/releases)
- 安装文档：见安装包内 `docs/` 目录（`install-single-windows.md` / `install-single-linux.md`）
- 软件为商业授权产品，安装包仅供评估与已授权用户使用；试用版超过 2 页的报表会带水印，
  导入授权文件（`.lic`）后即为正式版。

国内下载慢时可用加速前缀（把 Releases 附件地址整段接在后面）：

```
https://gh-proxy.com/https://github.com/terrychen111/gimbalx-report-dist/releases/download/v1.0.0/<文件名>
```
