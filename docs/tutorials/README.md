## 建议的阅读顺序

```text
1 → 2 → 3
      ↘ 4 → 5
```

3 和 4 是两条独立的进阶线（矩阵 vs 主从），按你的业务选；5 在最后，因为它是「交付前必做」。

## 每篇都有的三样东西

- **可执行 SQL**：复制粘贴就能建出示例表，不用自己想数据；
- **可对照的数字**：比如「A-1001 明细合计应为 1195.00」，一眼能看出是对了还是错了；
- **验收清单**：勾完就说明这个功能真的通了，而不是「看起来像」。

## 写教程的约定

- 界面名称以 v1.0.0 为准：功能区页签为「导航 / 报表 / 组件 / 组合 / 预览」；
- 数据源用真实的 MySQL 语法，不写伪代码；
- 不写「根据实际情况配置」这种废话——要么给具体值，要么给判断依据。

## 遇到问题

先看每篇末尾的「常见问题」，那里放的是真实踩过的坑（比如小计放错带区、子报表参数名不一致）。
仍然解决不了，加作者微信并附上：报表截图、数据源类型、报错原文。
