# 教程 5：导出与打印 —— 页面设置、页码、PDF 字体、Excel 保真

> 目标：把一张能看的报表，变成能直接发给客户、能直接打印的正式文件。
> 覆盖：A4 纵向/横向、页边距、页眉页脚与页码、PDF 中文与矢量、Excel 列宽与合并、批量与定时导出、水印。

## 1. 页面设置

选中**页面**（画布空白处或「页」节点）→ 属性面板：

| 项 | 建议值 | 说明 |
|---|---|---|
| 纸张 | A4 | 也有 A3 等可选 |
| 方向 | 纵向（列多的报表改横向） | 状态栏也能切 |
| 单位 | 毫米 | 设计时用毫米更贴近打印 |
| 页边距 | 上下 15 mm、左右 12 mm | 打印机不可打印区域一般 5 mm 以上 |
| 分页 | 自动 | 超出页面高度自动分页 |

**调试技巧**：设计态画布上会显示分页线，压线的地方预览一定会断行——先在设计态把元素挪开。

## 2. 页码与页眉页脚

- **页眉**带区：报表标题、公司名、Logo（图片元素）；
- **页脚**带区：页码表达式，常见写法 `第 {page} 页 / 共 {pages} 页`（函数名以界面提供的为准）；
- 只想在第一页显示一次的内容（如抬头），放 **报表头**；只在最后一页显示的（如合计、签字栏），放 **报表尾**。

注意：页眉/页脚是**每页**渲染，报表头/报表尾是**整份文档**一次——这是两类带区最本质的区别。

## 3. PDF

「预览」页签 → 格式选 **PDF** → 导出。

- **矢量输出**：文字和线条是矢量的，放大不糊；
- **中文显示**：如遇到方框/缺字，说明渲染端缺该字体，改用系统自带字体（宋体/黑体/微软雅黑）或把字体文件随包放置（以部署文档为准）；
- **条码/二维码**：v1.0.0 起导出为内嵌位图，可被扫码器识别（这是本版修复的重点项）；
- **图片**：贴图建议 150~200 dpi，过大会显著增大文件。

## 4. Excel

格式选 **Excel** 导出。检查三件事：

1. **列宽**：导出的列宽按模板宽度换算，模板里用毫米调好，Excel 里就基本对；
2. **合并单元格**：列头里手工合并的单元格会保留；数据区尽量避免纵向合并（Excel 里会变成一格）；
3. **数字格式**：模板里设了「千分位 + 两位小数」，导出后仍是数字（不是文本），可以继续求和。

> 经验：给客户的对账/明细，优先导 Excel（他能接着改）；给外部/归档，优先导 PDF（格式不会跑）。

## 5. 其他格式什么时候用

| 格式 | 典型用途 |
|---|---|
| PDF | 对外发送、归档、打印 |
| Excel | 客户要继续加工、做透视 |
| Word | 需要在此基础上写说明/公文 |
| SVG | 要矢量插图进设计稿、PPT |
| HTML | 邮件正文、嵌网页 |
| CSV / JSON / XML | 给系统对接、导入别的系统（不受试用水印影响） |

## 6. 水印

「报表」页签 → **水印**：可设文字、角度、透明度、平铺。用于「内部资料」「样本」「机密」这类标识。

试用版另有系统级水印：单份报表渲染后超过 2 页时，整份文档每页叠加 `[试用版 TRIAL]`；导正后自动消失。

## 7. 批量与定时

- **批量导出**：报表列表里勾选多张 → 批量导出（同一格式，打成压缩包）；
- **定时任务**：设置页 → 定时任务 → 选报表 + 参数 + 格式 + 频率（如每天 07:00 导出 PDF 到指定目录）；
- 定时任务在试用版同样可用，适合先验证「每天自动出一份日报」这类流程。

## 8. 交付前检查清单

- [ ] 分页线没有切到表格中间、没有把合计切到下一页；
- [ ] 页码总数正确（不是固定 1）；
- [ ] PDF 中文正常、条码可扫；
- [ ] Excel 打开后列宽可读、数字能求和；
- [ ] 换一台没装过本产品的电脑打开 PDF，字体不缺失（PDF 已内嵌）；
- [ ] 大报表（几千行）导出耗时与内存可接受——超大报表建议先在 SQL 里聚合。

## 常见问题

**PDF 里中文是方框**
字体缺失。换系统自带中文字体，或按部署文档把字体放进包的字体目录。

**导出的 Excel 打开提示「格式与扩展名不符」**
用 Excel 格式导出得到的是 `.xlsx`；如果浏览器把它存成了 `.xls`，手动改扩展名即可。

**页码「共 N 页」一直是 1**
说明分页没生效（页面高度设得过大，或内容被放进「单页模式」）。

**打印时右侧被裁掉**
纸张方向没改横向，或页边距过小落在了打印机不可打印区。

## 验收标准

- [ ] 导出的 PDF 在任何机器上打开字体正常；
- [ ] 页码与总页数正确；
- [ ] Excel 里的金额列可以直接 `SUM` 出正确合计；
- [ ] 条码/二维码用手机能扫出正确单号。
