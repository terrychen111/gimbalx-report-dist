# 教程 4：主从报表 —— 订单主表 + 明细子报表（一个订单一张卡）

> 目标：一张报表里，先按订单输出主信息（订单号、客户、日期），紧跟其后输出该订单的明细行；
> 每个订单占一块，分页时主信息与明细不拆开。
> 这是「单据打印」这类需求（订单、发货单、对账单）的标准做法。

## 准备数据

```sql
CREATE TABLE sales_order_line (
  id        BIGINT PRIMARY KEY AUTO_INCREMENT,
  order_no  VARCHAR(32)   NOT NULL,
  product   VARCHAR(64)   NOT NULL,
  qty       DECIMAL(12,2) NOT NULL,
  price     DECIMAL(12,2) NOT NULL
);

INSERT INTO sales_order_line (order_no, product, qty, price) VALUES
('A-1001','打印纸 A4',  10, 48.00),
('A-1001','硒鼓 88A',    2, 320.00),
('A-1001','文件夹',      6, 12.50),
('A-1002','打印纸 A4',  20, 48.00),
('A-1002','标签纸',      5, 26.00),
('A-1004','硒鼓 88A',    4, 320.00),
('A-1004','打印纸 A4',  15, 48.00);
```

## 思路

两个查询、两个模板：

| 模板 | 作用 | 查询 |
|---|---|---|
| `order-card`（本次新建） | 主表：循环订单，每个订单调一次子报表 | `orders_main`：订单头信息 |
| `order-lines`（已有/新建） | 子报表：接收 `order_no` 参数，输出明细 | `lines_by_order`：`WHERE order_no = :order_no` |

## 步骤

### 1. 先做子报表模板

新建报表，命名 `order-lines`：

1. 字典面板加查询 `lines_by_order`：

```sql
SELECT order_no, product, qty, price, qty * price AS amount
FROM sales_order_line
WHERE order_no = :order_no
ORDER BY id
```

2. 参数管理里加参数 `order_no`（文本，无默认值——由父报表传入）；
3. 排版：**列头**（产品 / 数量 / 单价 / 金额）+ **数据区**（四个字段）+ **报表尾**（`合计：SUM(lines_by_order.amount)`）；
4. 保存。这个模板自己单独预览时会要求输入 `order_no`，属于正常。

### 2. 做主报表

新建报表，命名 `order-card`：

1. 查询 `orders_main`：

```sql
SELECT order_no, customer, region, order_date
FROM sales_order
WHERE order_date >= :start_date
ORDER BY order_no
```

2. 加参数 `start_date`（日期，默认 `2026-01-01`）；
3. 排版：
   - **页眉**：`销售订单确认单`
   - **数据区**：一行放订单号、客户、日期（横向排开，作为「订单头」）
   - **数据区**（紧跟其后）：放一个 **子报表** 元素
4. 选中子报表元素 → 属性面板：
   - 子报表模板：选 `order-lines`
   - 参数映射：`order_no` ← `orders_main.order_no`（父级字段）
5. 选中订单头那行数据区 → 属性面板 → 勾选「与下一行同页/禁止跨页断开」（名称以界面为准），保证订单头和明细不被分页拆开。

### 3. 调样式

- 订单头加浅色底、订单号加粗；
- 每个订单之间加一条分隔线（用「形状」里的线，放在数据区底部）；
- 子报表里的列宽和父报表对齐（子报表宽度设为与父级可用宽度一致，超出会挤压）。

### 4. 预览

预期：按订单号顺序，每个订单一块：

```
销售订单确认单
订单号：A-1001   客户：杭州甲公司   日期：2026-01-05
产品          数量    单价     金额
打印纸 A4      10     48.00    480.00
硒鼓 88A        2    320.00    640.00
文件夹          6     12.50     75.00
合计：1,195.00
────────────────────────────────
订单号：A-1002 ...
```

校验：`A-1001` 明细合计应为 **1195.00**（480 + 640 + 75）。

## 常见问题

**子报表一片空白**
最常见是参数没映射上：父报表传的字段名要和子报表参数名完全一致（`order_no`），且类型都是文本。

**每个订单都显示全部明细**
子报表的 SQL 没带 `WHERE order_no = :order_no`，或者参数名拼错导致条件被忽略。

**明细把订单头挤到下一页**
订单头行没设「禁止跨页断开」，或子报表本身高度过大。检查子报表模板里是否有过大的页边距/空白带区。

**子报表报「找不到模板」**
模板名要写完整（保存时的报表名/编码）；子报表模板必须先保存过一次。

**导出的 PDF 里明细只有第一页**
父报表的数据区高度不够，子报表被裁剪。把子报表元素高度调大，或让它「自动伸展」。

## 验收标准

- [ ] 每个订单一块，订单头与明细在同一页；
- [ ] `A-1001` 明细 3 行、合计 1195.00；
- [ ] `A-1003`（没有明细数据）不会报错，显示空明细或跳过；
- [ ] 导出 PDF 后，分页处没有把订单头单独留在页尾。

## 延伸

- 单号条码：在订单头放一个 **条码** 元素，绑定 `orders_main.order_no`，扫码即可定位单据；
- 客户回执：报表尾加签字栏（用「形状」画两条横线 + 文本）；
- 批量出单：用定时任务按订单号范围批量导出 PDF（见 [教程 5](05-export-and-print.md)）。
