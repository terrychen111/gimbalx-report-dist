# 教程 3：交叉表（行列互换）做「区域 × 月份」的金额矩阵

> 目标：一张表，行是区域、列是月份、格子里是该区域该月的金额合计，右侧和底部自动带合计。
> 继续用 [教程 2](02-mysql-grouped-report.md) 的 `sales_order` 表，补 3 条 2 月数据。

## 准备数据

```sql
INSERT INTO sales_order (order_no, customer, region, amount, order_date) VALUES
('A-1009','南京壬公司','华东',1990.00,'2026-02-03'),
('A-1010','昆明癸公司','西南',720.00 ,'2026-02-09'),
('A-1011','佛山子公司','华南',2450.00,'2026-02-14');
```

## 步骤

### 1. 取数 SQL

新建查询 `crosstab_src`：

```sql
SELECT region,
       DATE_FORMAT(order_date, '%Y-%m') AS ym,
       amount
FROM sales_order
WHERE order_date >= '2026-01-01' AND order_date < '2026-03-01'
ORDER BY region, ym
```

**要点**：交叉表的列是数据里「长出来」的，所以 SQL 里必须先有一列用来当列维度（这里是 `ym`），不要在 SQL 里自己 `SUM ... GROUP BY`——聚合交给交叉表元素做，否则合计会重复计算。

### 2. 放交叉表元素

「组件」页签 → 把 **交叉表** 拖到数据区（或单独占一个数据区）。

### 3. 配置三个维度

选中交叉表 → 右侧属性面板：

| 配置项 | 填什么 |
|---|---|
| 数据源 / 数据集 | `crosstab_src` |
| 行字段（行维度） | `region` |
| 列字段（列维度） | `ym` |
| 值字段（度量） | `amount`，聚合方式 **SUM** |
| 行合计 | 打开 |
| 列合计 | 打开 |
| 空值显示 | `-` 或留空 |

### 4. 调样式

- 表头行加底色、加粗；
- 值列数字格式：千分位 + 两位小数、右对齐；
- 合计行/列加浅灰底色（属性面板 → 单元格样式 → 合计区域）。

### 5. 对数字

预览结果应等于下表：

| 区域 | 2026-01 | 2026-02 | 合计 |
|---|---|---|---|
| 华东 | 8,140.50 | 1,990.00 | 10,130.50 |
| 西南 | 2,480.00 | 720.00 | 3,200.00 |
| 华南 | 5,801.15 | 2,450.00 | 8,251.15 |
| 西北 | 760.00 | - | 760.00 |
| **合计** | **17,181.65** | **5,160.00** | **22,341.65** |

对不上时按顺序查：① SQL 是否已 `GROUP BY`（应去掉）② 值字段聚合方式是否 SUM ③ 列维度是否选的 `ym` 而不是 `order_date`。

## 常见问题

**列数太多，横着排不下**
把列维度换成季度（`CONCAT(YEAR(order_date),'-Q',QUARTER(order_date))`）或只保留 Top N；也可以在交叉表属性里限制列数。

**列顺序乱**
SQL 里 `ORDER BY ym`，或交叉表属性里指定列排序（按列名/按值）。

**合计是明细的几倍**
说明 SQL 里已经聚合过一次，交叉表又聚合了一次（笛卡尔放大）。SQL 只出明细行，聚合只在一处做。

**中文列名想显示成「1月」**
列维度可以在属性里配「列标题格式」，或用 SQL 直接输出 `CONCAT(MONTH(order_date),'月')` 作为 `ym`。

## 验收标准

- [ ] 表格 4 行 × 2 列数据格，行合计与列合计都有；
- [ ] 五个数字（4 行合计 + 1 个总合计）与上表一致；
- [ ] 西北 2 月显示 `-`（不是 0，也不是空白导致的错位）；
- [ ] 导出 Excel 后是真正的二维表（可继续在 Excel 里做透视）。
